**Real bugs found and fixed during verification, not glossed over:**
1. A CSS specificity bug hid the entire matrix on desktop despite JS building it correctly — two rules targeting the same selector, the wrong one won by source order. Fixed.
2. Cumulative Layout Shift started at 0.446 (a real, visible reflow) because `font-display: swap` (specified by N8) means the fallback font always renders first, and bold Arial/Georgia/Menlo don't match Archivo/Source Serif 4/JetBrains Mono's widths — measured in a real browser, not guessed. Fixed with metric-matched fallback `@font-face` declarations (`size-adjust`, `ascent-override`, `descent-override`) calibrated against real rendered text, which brought Performance to 99 and CLS to ~0 in most runs.
3. **Not fully fixed:** in 1 of 5 runs, a small residual shift (CLS 0.226, Performance 88) still shows up from Source Serif 4's swap. Root cause is diagnosed — the mobile view's default capability-grouping renders 24 card instances, and any sub-pixel-per-line rounding difference between the fallback and real font accumulates over that much repeated text into a measurable shift far down the page. This is real remaining work, not resolved — flagging rather than claiming it's done. Likely full fix if you want it pursued: reduce how much duplicate content renders by default, which is a design change, not a CSS tweak.
